# BlueTrade AI — development installers

Public binary distribution only. Source remains in the private Trading repository.

Download actual Windows development candidates and SHA-256 checksums from [Releases](https://github.com/Matviyyt/BlueTrade-AI-releases/releases). The product site is https://bluetrade-ai.vercel.app.

Windows candidates are unsigned. Mainnet automation is locked. macOS artifacts are unavailable until successful build and signing/notarization verification. These are not production-certified releases.

Use the top-right Login button in the desktop app to store a Bybit API Key + API Secret and NVIDIA NIM API Key locally in OS-encrypted storage. Never post keys in this repository or its issues. News uses Nemotron 3 Super; trade context uses Nemotron 3 Ultra. Provider validation requires your own credentials.

Paper mode uses real public market data and virtual funds. No strategy profitability or AI accuracy is guaranteed. Automated trading runs locally; the computer, app and internet connection must remain available. Cryptocurrency trading involves substantial risk; past performance, backtests and AI analysis do not guarantee future results.
